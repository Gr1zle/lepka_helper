# Контрольная версия 0.6.0 — 29.10.2026

Назначение: предварительная проверка приложения на компьютере перед оформлением
документов. Это промежуточная версия, а не заявление о выполнении всего ТЗ.
Новые крупные функции сегодня не добавляются. Исходное ТЗ и его дата сдачи
не изменяются. Документы должны описывать именно перечисленное ниже поведение.

## Реализованный состав

| Модуль | Фактическое поведение |
| --- | --- |
| Аккаунты | Регистрация, почтовое подтверждение, вход/выход, восстановление, смена email/пароля, удаление, сессии и ограничения попыток. Почтовые сценарии требуют Resend; тестовый вход письма не требует. |
| Профиль | Ник, био, возрастная категория, любимые цвета, аватар с устройства, светлая/тёмная тема, свои работы и счётчики. |
| Цвета | 12 базовых цветов, смеси 2–5 цветов, нормализация процентов и граммов, сохранение/удаление/открытие, приближённый подбор по HEX, PNG-экспорт. RGB-модель приближённая. |
| Поиск и уроки | 6 встроенных текстовых уроков со схематичными SVG, материалы, шаги, сохранение прогресса, фильтры, генерация идей и добавление в проекты. |
| Проекты | Название, категория, необязательная дата, заметки, редактирование, этапы, фотографии, смеси, прогресс и подтверждённое удаление. Новый завершённый этап требует фото. |
| Публикации | 1–10 проверенных фото, описание/категория/теги, лента, свои работы, лайки, комментарии с ограничениями. |
| Мастер-классы | Публикация выбранных шагов проекта, сложность/время, материалы/инструменты, фотографии шагов, прогресс читателя, сохранение рецепта, личная копия проекта. |

## Что стабилизировано для проверки

- `main.py --local` явно запускает местный режим на ПК с тестовым входом. Файлы
  конфигурации и данные сервера не заменяются; версия без API не требует хостинга.
- При недоступном сервере раздел показывает ошибку и «Повторить загрузку».
  Навигация не показывает содержимое прежней вкладки под новым названием.
  Повторная попытка снова проверяет сессию, скрытого локального входа вместо API нет.
- Проект и этап удаляются после подтверждения. Отмена и обработчик от старой
  сессии не удаляют данные. Ранее опубликованные снимки проекта самостоятельны.
- Чекбоксы согласия, материалов урока и любимых цветов обновляют отображение
  сразу после нажатия. Настройки языка/уведомлений в старой базе сохраняются.
- Кнопка Google-входа и неработающее «Запомнить меня» убраны с экрана входа.
  Выбор English, переключатель push и информационная заглушка «Избранное»
  убраны из настроек. Это изменение интерфейса, а не удаление требований ТЗ.
- Баннер «Челлендж недели» переименован в «Идею для практики». Он не является
  конкурсом. Onboarding не обещает отсутствующую галерею 3D.
- «О приложении» содержит версию и границы готовности, в регистрации доступно
  описание использования и хранения данных.
- `scripts.create_server_demo` однократно создаёт обычного подтверждённого
  тестового пользователя в существующей серверной базе. Чужие пароли и занятые
  ники не заменяются, общая регистрация не теряет подтверждение email.
- Соединение SQLite при создании пользователя закрывается также при конфликте
  email/ника. Исключение не оставляет базу открытой, что важно для Windows.
- Версия приложения и будущего мобильного пакета берётся из `app_info.py`.
  `scripts.prepare_review` создаёт ZIP по явному списку, с манифестом и хешами,
  без `.env`, ключей, баз, окружения Python и личных настроек адреса API.

## Основа для документации

Рабочая точка входа — `main.py`; активные экраны находятся в `views/`.
Предметные сервисы работают с `database.py`. В серверном режиме аккаунты идут
через `account_gateway.py`, сообщество — через `community_gateway.py` к
`backend/main.py` и `backend/community.py`. SQLite сервера и клиента разделены.
Пароли хешируются PBKDF2, сессии/почтовые коды хранятся в виде хешей.

На устройстве остаются личные проекты, палитра и прогресс встроенных уроков.
В режиме API на сервере находятся аккаунты, публикации, фотографии, обсуждения
и прогресс мастер-классов. В местном режиме они находятся в одной локальной базе.
Схемы архитектуры и БД в пояснительной записке должны отражать это разделение.

## Открытые требования и ограничения

Не реализованы: Google OAuth, долговременное «Запомнить меня», полный английский
интерфейс, избранное уроков/моделей, 3D/AR и обработка фото-референса, фото/видео
шагов встроенных уроков, камера, перетаскивание этапов, статистика завершений по
месяцу/году, импорт/экспорт проекта JSON, калькулятор объёма и таймер, полноценная
модерация/админ-панель с причиной и журналом, push и напоминания, автодополнение,
история поиска, конкурсы и полная оффлайн-очередь/синхронизация личных данных.
Не все детали экранов и требований надёжности ТЗ закрыты этой версией.

PNG удовлетворяет альтернативе экспорта изображения; PDF отдельно не реализован.
Модели, видео и фотоматериалы не заменяются демонстрационными SVG. В составе
этой версии нет готового проверенного APK; Android и отдельное окно Windows
требуют отдельной проверки в оставшиеся дни. Публичного сервера и постоянного
HTTPS-адреса ещё нет. Платные сервисы не подключались.

## Проверки

На Linux, Python 3.12, Flet 0.28.3 прошли **227 тестов, OK**: прежние 215 и 12
новых проверок контрольной поставки. Полный набор выполнен с
`LEPKA_API_URL=https://example.invalid`, пользовательский API не использовался.
Проверены повторная загрузка раздела и проверка сессии, отмена/подтверждение
удаления, старые обработчики, сохранность прежних настроек, отображение отметок,
серверный тестовый аккаунт без перезаписи данных, исключение личных файлов из
ZIP и проверка хешей. `pip check` и `git diff --check` прошли.

В настоящем Chromium при 390 × 844 проверены: запуск из другой папки с
`--local` и намеренно неверным адресом API, тестовый вход, все пять вкладок,
материалы и прогресс урока, выбор аватара настоящим FileChooser и HTTP-загрузка,
отметка любимого цвета и сохранение профиля. Профиль просмотрен также при
ширине 320 пикселей. Проверки SQLite подтвердили сохранённые фото и отметки,
ошибок JavaScript не обнаружено.

Отдельно повторён серверный сценарий: один API, два процесса Flet с разными
клиентскими базами, два аккаунта, общий мастер-класс, лайк, комментарий,
прогресс и копирование рецепта. Серверный режим продолжает работать.

ZIP распакован в отдельную папку. Проверены все хеши манифеста, отсутствие баз
и секретных файлов, запуск из другой рабочей папки, SVG-ресурсы, автоматическое
создание нового местного тестового аккаунта и вход в настоящем Chromium.
Архив исходников содержит 102 файла с манифестом; это не сборка EXE или APK.
