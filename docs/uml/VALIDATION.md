# Проверка результатов UML

- Pyreverse: 141 явно выбранный Python-файл, 53 класса; множество классов совпадает с AST-инвентаризацией. Узлов сторонних библиотек/тестов нет.
- Все 22 внутренние связи наследования совпадают с объявлениями родителей в исходниках.
- Одна связь поля найдена Pyreverse; одна восстановлена только из явной аннотации `list[PhotoInput]` и её ограничений. Происхождение разделено в manifest.
- Все исходные рёбра сохранены в разбиении; каждый класс включён в подробную схему своей подсистемы.
- Все 11 SVG разобраны XML-парсером; 11 PNG проверены Pillow (целостность и 300 dpi); 11 PDF имеют корректную сигнатуру.
- DOT всех схем действительно отрендерены Graphviz; PUML содержит те же 53 класса. Неизменённые исходные DOT/PUML Pyreverse сохранены в raw.
- Содержимое 141 Python-файла после генерации совпадает с хешами до неё и с commit исходников. Изменения Git ограничены docs/uml.
- Подробная схема клиента визуально просмотрена после исправления размещения секций классов: название, поля и методы расположены вертикальными секциями, длинные сигнатуры перенесены без удаления параметров.
- В Microsoft Word файлы в этой среде не открывались: подготовлены стандартные SVG и PNG; действия вставки описаны в README. APK не пересобирался, поскольку код не менялся.
