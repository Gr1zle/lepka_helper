# Порядок этапов проекта

Продолжение после подтверждённой пользователем Android-версии 0.6.1.
Разработка ведётся в GitHub; отдельная APK для этого изменения не собирается.

В карточке проекта доступна кнопка «Порядок этапов». Для двух и более этапов
она открывает окно: перетаскивание (на телефоне — длительным нажатием), стрелки
вверх/вниз, «Сохранить порядок» и «Отмена». До сохранения меняется только черновик.

Порядок хранится в `projectSteps.sortOrder`. При первом обновлении схемы прежние
этапы получают позиции в прежнем порядке `createdAt, stepId`; повторный запуск
миграции уже сохранённый порядок не меняет. Новые этапы добавляются в конец.
Фото, ID этапов, описания, отметки выполнения и прогресс проекта не заменяются.
Перед обновлением своей рабочей копии сохраните резервную копию каталога данных.

Сохранение выполняется транзакционно с проверкой владельца и полного списка
этапов. Если после открытия окна список или его порядок уже изменились, операция
отклоняется: нужно открыть окно снова. Обработчик от старой сессии не сохраняет
изменения. Новый мастер-класс следует текущему порядку проекта; ранее
опубликованный мастер-класс остаётся самостоятельным снимком.

Полный набор: 241 тест, OK; `pip check` и `git diff --check` пройдены.
Проверки используют временные базы: миграция и повторный запуск, сохранность
фото/прогресса, новые этапы в конце, чужие/повторные/пропущенные ID, конфликт
между окнами, отмена, событие перетаскивания, сохранение и отзыв сессии. Новый
порядок проверяется также в опубликованном мастер-классе. Настоящее перетаскивание
в браузере/на Android для этого изменения ещё не проверялось.

Проверка на ПК: открыть проект с тремя этапами, изменить порядок стрелками и
перетаскиванием, отменить. Затем повторить и сохранить. Открыть проект снова,
сверить фото и отметки; добавить новый этап и убедиться, что он последний.

Следующие блоки: JSON-импорт/экспорт проектов и статистика завершений; калькулятор
количества пластилина и таймер; отдельная работа над 3D и доступным HTTPS API.
После функциональных этапов — редизайн, итоговая Android-проверка и документация.
Эти пункты остаются открытыми требованиями, исходное ТЗ не изменяется.
