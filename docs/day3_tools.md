# Инструменты для лепки — 28 октября 2026

Продолжение существующего приложения по плану на 28 октября. Исходный `docs/ТЗ`, включая дату сдачи, не изменён. Этот отчёт уточняет состояние реализации после `day1_requirements_audit.md`; он не отменяет открытые требования.

## Что изменено

### Color Mixer и рецепты

- Для сохранения и экспорта требуется 2–5 разных цветов базовой палитры. Один цвет допускается в промежуточном предпросмотре. Проверяются идентификаторы, HEX, конечные числовые доли 0–100 и положительная сумма долей.
- Доли приводятся к 100% с точностью 0,1%. Вес необязателен: пустое поле означает 100 г. Принимаются точка и запятая, минимальный вес 0,01 г. Ошибочные значения, отрицательные числа, `nan` и бесконечность отклоняются, вместо подстановки 100 г.
- Массы округляются до 0,01 г методом наибольших остатков: сначала берутся целые сотые, затем остаток распределяется между компонентами. Например, для трёх равных долей на 1 г получаются 0,34 / 0,33 / 0,33 г. Сумма соответствует округлённому общему весу. При очень малом весе отдельные компоненты могут округлиться до 0 г.
- Итоговый HEX — взвешенное среднее каналов RGB. Это приближение: реальные пигменты пластилина смешиваются иначе. Алгоритм подбора по HEX остаётся приближённым и перебирает прежние варианты до четырёх компонентов; ручной режим поддерживает пять.
- Сохранённую смесь можно открыть для повторного расчёта и удалить. Проверяется принадлежность пользователю. Повреждённый старый рецепт не обрушает вкладку и не переписывается автоматически.
- TXT заменён PNG с названием, образцом цвета, HEX, весом, процентами и граммами. Кириллица выводится включённым DejaVu Sans; лицензия находится рядом со шрифтом. PNG содержит метаданные самого рецепта, без данных аккаунта и секретов. PNG выбран как один из разрешённых ТЗ форматов; PDF не добавлен.
- В браузере PNG выдаёт маршрут веб-приложения через одноразовый случайный адрес на 10 минут. Файл хранится в памяти, после скачивания ссылка недействительна; журнал доступа с адресами выключен. Настольный обработчик предлагает путь `.png` и отказывается перезаписывать существующий файл.
- Подбор рецепта проверяет вес до запуска фонового поиска и не оставляет надпись «Подбираю рецепт…» при ошибке ввода.

### Уроки и идеи

- Сохранены шесть встроенных текстовых уроков. Добавлены локальные схематичные SVG-иллюстрации, фильтры сложности, времени и наличия видео, поиск по словам и материалам. Видео отсутствует, поэтому соответствующий фильтр возвращает пустой список.
- В уроке доступны чек-лист материалов и отметки выполненных шагов. Для вошедшего пользователя сохраняются материалы, шаги и последняя позиция; завершение определяется по всем выполненным шагам. Гость может читать уроки без сохранения личного прогресса.
- Таблица `lessonProgress` добавляется при инициализации существующей базы. Записи разделены по пользователю и уроку, удаляются при удалении аккаунта. Остальные данные и пароли не заменяются.
- Генератор учитывает тематику, сложность, тёплую/холодную/случайную гамму и количество цветов 1–5.
- При добавлении урока в проект копируются все текстовые шаги; для идеи создаются четыре начальных этапа. Проект и этапы сохраняются одной транзакцией: при ошибке частичного проекта не остаётся.

### Проекты

- Добавлены редактирование названия, категории, описания и дедлайна, изменение текста этапа и календарь выбора даты. Ручной ввод и пустой дедлайн сохранены; прошедшие даты допустимы. Календарь ограничен 1900–2100 годами; ручной ввод проверяется прежним календарным валидатором.
- Чтение, удаление, отметка и редактирование проекта/этапов требуют владельца. Обработчики личных действий проверяют действующую сессию, в том числе после выхода в другой вкладке.
- Сохранены добавление/удаление этапов, пересчёт прогресса и транзакционное удаление проекта с его этапами.

Большой `home_view.py` сохраняет прежнюю структуру экранов. Расчёты находятся в сервисах, а формирование PNG, выдача скачивания и поле календаря вынесены в небольшие отдельные модули.

## Выполненные проверки

Среда: Linux, Python 3.12.14, Flet 0.28.3, Pillow 13.0.0.

- `python -m unittest discover -s tests -v`: **112 тестов, OK**. Добавлено 29 проверок к предыдущим 83. Новые проверки охватывают нормализацию и округление, ошибочные значения, PNG и одноразовое скачивание, сохранённые рецепты, прогресс уроков, фильтры и идеи, создание проекта с откатом транзакции, права владельца и обработчики Flet. Прежние проверки аккаунтов и сервера также прошли.
- Все тесты используют временные базы и каталоги. Письма имитируются; пользовательская база не удалялась и не использовалась для проверок.
- Отдельный процесс `main.py` запущен из другой рабочей папки с временными данными. Через настоящий WebSocket-протокол Flet выполнены вход, переход к цветам, выбор белого и чёрного, экспорт. Полученная HTTP-ссылка вернула PNG-вложение с `#808080` и суммой 100 г; повторное скачивание вернуло 404. SVG урока выдан по HTTP из абсолютной папки ресурсов. Это проверка реального транспорта, а не визуальное управление браузером.
- Сгенерированный PNG с пятью цветами просмотрен: кириллица, образцы и таблица читаются.
- `python -m pip check`: несовместимых зависимостей нет. `git diff --check`: замечаний нет.

Полноценный графический браузер, настоящее окно выбора файла Windows и Android APK здесь не проверены. Для настольного сохранения проверен вызов и обработчик результата FilePicker, а не системное окно.

## Как проверить на своём компьютере

Перед обновлением сохраните копию базы. Не удаляйте её для запуска новой версии. Если используете сервер аккаунтов, оставьте прежнюю настройку сервера и не передавайте клиенту ключ Resend.

Из папки проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py
```

1. Войти. Выбрать белый и чёрный в «Цветах»: равные доли дают `#808080`, при 100 г — по 50 г.
2. Выбрать 3–5 цветов и изменить доли. Проверить сумму 100% и общий вес. Ввести `НЕ ЧИСЛО`, `-1`, `nan`: сохранение, экспорт и подбор должны сообщить об ошибке. Пустое поле веса даёт 100 г.
3. Сохранить тестовую смесь; открыть её из «Моих смесей», экспортировать PNG и открыть скачанный файл. Удалить только этот тестовый рецепт. В другом аккаунте смесь не видна.
4. В «Поиске» выбрать «Начинающий» и время до 30 минут; проверить изменение результатов. Фильтр видео даст пустой список. Открыть урок, отметить материал и шаг, выйти из урока и вернуться: отметки восстановятся.
5. Добавить урок как проект и проверить все его этапы. В генераторе выбрать тематику и гамму, создать идею, добавить её в проекты и проверить четыре этапа.
6. Изменить тестовый проект и текст этапа, выбрать календарём дедлайн. Проверить отклонение `31.04.2026`. Отметить этапы, удалить один, сверить прогресс. Удалить тестовый проект и убедиться, что чужие проекты не затронуты.
7. Для проверки настоящего окна сохранения PNG отдельно установить `flet[desktop]==0.28.3` и запустить `main.py --desktop`. Эта ручная проверка ещё требуется.

## Открытые требования

Текстовые уроки и схематичные рисунки не закрывают фото/видео шагов. Остаются заметки/обмен уроком, общий поиск и история, фото этапов (включая требование фото при завершении), изменение порядка этапов, JSON-импорт/экспорт проекта, статистика завершений по периодам, push-напоминания, скан цвета камерой, расчёт массы по объёму, таймер, 3D/AR и другие открытые пункты исходного аудита.

Смеси, проекты и прогресс уроков ещё не синхронизируются с сервером. Публичное HTTPS-размещение сервера и Android-сборка этим этапом не выполнялись. Следующий пункт плана — сообщество, интерфейс и первая мобильная сборка. Наличие этих ограничений не означает исключения требований из ТЗ.
