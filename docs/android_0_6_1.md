# Android 0.6.1 — 31.10.2026

Пользователь подтвердил установку и запуск APK 0.6.0 на Android. Сообщены два
замечания: фон при смене темы обновлялся только после перезапуска, а каждый новый
запуск требовал входа. Редизайн отложен до завершения функциональных исправлений.

В 0.6.1 фон страницы, главного представления и его контейнера использует
семантический цвет `surface`. Светлая тема задаёт белую поверхность, тёмная —
`#121212`; цвет обновляется вместе с темой.

Только в локальной нативной Android-версии после входа сохраняется токен сессии
в закрытом каталоге данных приложения. Файл `device_session.json` создаётся
атомарно с правами 0600; пароль в него не записывается. При запуске токен
проверяется по SQLite: срок, блокировка пользователя, подтверждение почты и отзыв.
Срок сессии не менялся: 12 часов. Выход удаляет сохранённый токен; истёкшая,
отозванная или повреждённая запись не разрешает автоматический вход.
Серверные токены и вход в браузере этим механизмом не сохраняются. Android
Keystore в данном решении не используется; защита файла опирается на каталог
приложения и права ОС.

Проверено: 235 автоматических тестов, `pip check`, `git diff --check`.
Отдельные проверки покрывают смену темы, вход → перезапуск → восстановление
пользователя и темы → выход, истечение/отзыв сессии, повреждённый и поддельный
файл, ошибку записи и отсутствие сохранения в браузере/серверном режиме.

APK собран Flet 0.28.3 / Flutter 3.29.2 / JDK 17 для ARM64, Android 9+.
Номер сборки 2 (итоговый Android versionCode 2002 с учётом ABI).
Подпись проверена и совпадает с APK 0.6.0. Проверены целостность архива,
актуальные исходники внутри APK и отсутствие пользовательской БД/файла сессии.
Проверка изменений на физическом устройстве ожидается от пользователя.

Установить поверх 0.6.0, не удаляя приложение. Один раз войти: старая версия
сессию не сохраняла. Переключить тему туда и обратно; закрыть приложение,
открыть снова; проверить вход, тему и прежние проекты. Затем проверить явный
выход. Локальные данные хранятся в SQLite, публикации не общие между телефонами.
