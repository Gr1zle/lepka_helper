# Фактические функциональные требования и статусы

Статусы готовности: **READY** — реализовано и проверено указанным способом; **PARTIAL** — часть реализации/проверки отсутствует; **BLOCKED** — проверке мешает среда/внешняя зависимость; **NOT READY** — требуемой реализации нет. PASS/FAIL/NOT TESTED относятся к конкретным испытаниям, а не автоматически ко всему требованию.

Сверка: исходное `docs/ТЗ` плюс последующие прямые уточнения пользователя (общий Wi-Fi-сервер, обязательный английский, новая навигация, правила фотографий и завершения, удаление кнопок черновиков). Прежние отчёты не заменяют результаты текущих испытаний. Ссылки на фактические тесты — [протокол](TEST_CASES.md) и [полный реестр](AUTOMATED_TESTS.md).
