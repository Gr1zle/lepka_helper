**Как читать результат.** Ниже указаны воспроизводимые пользовательские шаги и связанный автоматизированный эквивалент. PASS относится к выполненным assertions/контролам/API указанного метода, а не к якобы выполненному ручному прогону Android. - Профиль/навигация/остальные функции, не изменённые на финальном этапе, проверялись текущим полным набором, а не автоматически объявлены PASS по старым отчётам. Исторические ошибки №33 и их исправления описаны отдельно; они не выданы за новые находки.
- Ошибки подготовки тестовых fixtures/селекторов браузера не записываются как ошибки пользовательского приложения. Финальный протокол содержит только фактически выполненный законченный прогон.

## Идентификация прогона

JSON фиксирует исходный commit, изменения рабочего дерева и SHA-256 runtime-файлов. В этом прогоне `runtimeUnchanged=true`: код не менялся во время проверки. Упакованные файлы APK отдельно сопоставлены с теми же исходниками.

Браузерная приёмка: [B01–B09](evidence/browser_core.json), [B10–B15](evidence/browser_projects.json), логи и исполнявшиеся сценарии рядом. Синтетические аккаунты и базы существовали только в тестовых каталогах.
