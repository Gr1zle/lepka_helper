# API-инвентаризация

Сгенерировано из `createApp().openapi()`; контракты тел, ограничения и схемы авторизации — [openapi.json](evidence/openapi.json). Версия протокола OpenAPI metadata: 1.1. Она отличается от версии APK/пакета поставки. `HTTPBearer` в OpenAPI не всегда означает обязательность: публичные маршруты используют optionalUser; фактическая авторизация проверяется интеграционными тестами.
