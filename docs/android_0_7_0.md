# Android 0.7.0 — 01.11.2026

Контрольная APK-сборка ветки `feature/wifi-local-server`, включая предыдущие функциональные блоки до №22. Android 9+, ARM64, build number 3. Локальный режим доступен по умолчанию; сохранённое подключение к серверу имеет приоритет над режимом демосборки.

На экране входа: **Подключение к серверу / Wi-Fi** → адрес `http://IPv4-компьютера:8000` → явно разрешить HTTP → проверить связь → сохранить → войти в серверный аккаунт. Адрес хранится в закрытой папке приложения. Изменение IP не требует пересборки. Серверные токены при перезапуске пока не сохраняются.

Инструкция запуска сервера без Docker: [wifi_server.md](wifi_server.md). Компьютер и телефон подключаются к одному роутеру, компьютер должен оставаться включённым. HTTP не шифрует данные, используйте учебный пароль в доверенной сети. Личные проекты не синхронизируются автоматически, серверные аккаунты отделены от локальных.

Для обновления установите поверх 0.6.1, не удаляя приложение: это сохраняет локальные данные. После проверки локальных проектов выйдите из аккаунта и настройте сервер. Для возврата к прежним данным выберите «Локальный режим» в том же окне подключения.

Физический Android недоступен в среде сборки; проверка на телефоне ожидается от пользователя.
