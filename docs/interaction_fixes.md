# №33: открытие постов, язык и публикация без конкурса

Версия 0.17.0. Исправления по проверке Android пользователем после №32.

## Открытие поста

Страница с индикатором открывается до сетевого запроса. Данные загружаются в фоне. Повторные нажатия на одну карточку не создают другие страницы или запросы; после «Назад», выхода и смены аккаунта поздний результат не вставляется обратно в интерфейс. Ошибка связи даёт кнопку повторной загрузки.

Просмотр публичного поста больше не делает отдельный `/auth/me` перед навигацией. Для действий записи проверка сессии сохраняется. Новый сервер возвращает пост, первые 20 комментариев, сведения о мастер-классе, права для видимости кнопок и превью первого фото одним запросом `/community/posts/{id}/detail`. Фото уменьшается до 960 px для отображения, оригинал остаётся в базе. Чтение одного поста больше не загружает все работы автора. Страницы комментариев и действия по-прежнему проверяются сервером.

На сервере 0.15/0.16 предусмотрен старый протокол с параллельным чтением; для наибольшего ускорения следует обновить сервер до 0.17 с прежним каталогом данных.

## Язык

Переключатель языка был создан, но пропущен при сборке окончательного экрана профиля. Теперь он находится прямо в разделе «Настройки», вне раскрывающихся групп, и применяется при выборе. Выбранный перед входом язык применяется также к существующему тестовому/серверному аккаунту и сохраняется в профиле. Без явного выбора применяется прежняя настройка аккаунта.

Flet 0.28 подавляет повторный переход на тот же маршрут. Для языка теперь вызывается явная перерисовка текущего маршрута; иначе поля могли сменить подписи, а заголовки и кнопки оставались на прежнем языке. После смены языка в профиле сохраняется открытый раздел настроек.

## Создание публикации

Публикация создаётся отдельной страницей на всё доступное пространство экрана. Кнопки «Сохранить черновик», «Мои черновики» и «Новый черновик» убраны из формы. Ранее сохранённые данные черновиков не удаляются; автоматическая очередь при недоступной сети сохранена.

Пустой ключ варианта «Без конкурса» заменён на непустой технический ключ `none`. Flet/Android мог вернуть вместо пустого ключа видимый текст, который попадал в `int()`. Все формы публикации используют общий разбор выбора; некорректный вариант даёт понятное сообщение. Обновлять список конкурсов перед отправкой больше не требуется.

Защита от повторной отправки включается до сетевой проверки аккаунта: кнопка блокируется сразу и показывает отправку. Повторные нажатия не создают запросов или копий публикации. Существующая серверная идемпотентность сохранена. Промежуточный прогресс загрузки фотографии больше не запрашивает `/auth/me` на каждом событии; завершение загрузки проверяет сессию.

Строка `GET /auth/me ... 200 OK` — штатная успешная проверка входа, не ошибка публикации.

## Проверки и обновление

Регрессии проверяют 30 нажатий, одну загрузку/страницу, возврат до ответа, повтор после ошибки, отсутствие лишних запросов по начальному набору данных, язык до входа в тестовый аккаунт, видимый выбор в профиле и перерисовку неизменившегося маршрута. Отдельно проверяется публикация с фото без обновления конкурсов, одна запись при 30 повторных нажатиях и ограниченный ответ API с правильным владельцем комментариев.

APK устанавливается поверх прежнего. Для сервера остановите старый процесс Ctrl+C, распакуйте новый пакет отдельно и запустите с прежним `--data-dir`. Базу и настройки удалять не нужно. Физические Android и домашняя Wi-Fi сеть требуют повторной проверки пользователем; здесь используется браузер и настоящий сервер с синтетическими данными.

Все 515 автотестов прошли. Совместимость старого протокола отдельно проверена через настоящий API с имитацией отсутствующего нового маршрута.

В браузере пройдены выбор English до входа в существующий русскоязычный аккаунт, создание поста с явным выбором No challenge без обновления конкурсов, загрузка фото, открытие/возврат, серия из 30 событий нажатия и смена языка в профиле. На 30 событий зарегистрирован один запрос detail и одна страница. Холодное/повторное открытие на этом синтетическом локальном стенде заняло около 0,46/0,66 с; это не измерение физического Android или домашней Wi-Fi сети.
