# Сервер на компьютере и телефон в одной Wi-Fi сети

Хостинг, домен и Docker не требуются. Компьютер хранит серверную базу, телефон подключается по локальному адресу. Компьютер может быть подключён к тому же роутеру кабелем. При выключенном компьютере или вне домашней сети сообщество недоступно. Личные проекты остаются на устройстве, автоматической синхронизации всех данных нет.

## Windows, первый запуск

Установите Python 3.12. Откройте PowerShell в папке проекта или подготовленного серверного пакета:

```powershell
py -3.12 -m venv .server-venv
.\.server-venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.server-venv\Scripts\python.exe -m scripts.run_wifi_server
```

Сервер работает, пока открыто окно. Данные по умолчанию находятся в `LepkaHelperServer` внутри домашней папки Windows; последующие запуски используют ту же базу. Если сервер уже запускался с другой папкой, передайте её через `--data-dir`, чтобы продолжить работу со старыми аккаунтами. Остановка — Ctrl+C, повторный запуск — последняя команда.

Разрешите Python доступ в брандмауэре для **частной домашней сети**. Проброс портов роутера не нужен. Команда слушает сетевые интерфейсы компьютера; запускайте её в своей доверенной сети.

## Подключение телефона

1. Подключите телефон и компьютер к одному роутеру. Гостевая сеть может запрещать связь устройств.
2. Выполните на компьютере `ipconfig`, найдите IPv4 именно Wi-Fi/Ethernet адаптера, например `192.168.1.20`.
3. На телефоне откройте браузер и `http://192.168.1.20:8000/ready`. Ожидается `{"status":"ready"}`. Если ответа нет, проверьте брандмауэр, адрес, VPN и изоляцию клиентов роутера.
4. В приложении на экране входа нажмите **«Подключение к серверу / Wi-Fi»**, введите `http://192.168.1.20:8000`, разрешите HTTP в своей сети, проверьте связь и сохраните.
5. Войдите в серверный аккаунт. Для возврата к данным локального режима выйдите из аккаунта и выберите «Локальный режим» в том же окне.

Адрес сохраняется на устройстве, пересобирать APK при смене IP не требуется. Старый установленный APK ещё не содержит этого окна: потребуется одна обновлённая сборка. `127.0.0.1` на телефоне означает сам телефон. Если IP компьютера меняется, можно закрепить его в настройках роутера. Веб-клиент использует общий адрес процесса; настройка предназначена прежде всего для установленного приложения.

HTTP не шифрует пароли и данные. Используйте учебные аккаунты и отдельные пароли в доверенной сети. Для публичного доступа по интернету требуется HTTPS.

## Учебный вход без отправки почты

После первого запуска оставьте сервер работать и в другом PowerShell выполните:

```powershell
.\.server-venv\Scripts\python.exe -m scripts.create_server_demo --data-dir "$HOME\LepkaHelperServer"
```

Создаётся обычный подтверждённый пользователь `test@email.com`, пароль `Test123456`; существующий аккаунт не заменяется. Все устройства с этим входом представляют одного пользователя. Для разных авторов нужна регистрация отдельных аккаунтов с подтверждением почты; настройка Wi-Fi сама по себе не обеспечивает отправку писем.

## Docker, если он уже установлен

```powershell
$env:LEPKA_BIND_ADDRESS = "0.0.0.0"
docker compose -f backend/compose.yml up -d --build api
```

Телефон использует IPv4 компьютера, как выше. Caddy и профиль `public` для домашней сети не нужны. По умолчанию Compose по-прежнему публикует API только на localhost.

Физический телефон в этой среде недоступен: подключение по домашнему Wi-Fi нужно подтвердить на устройстве пользователя. APK 0.7.0 собран: [скачивание и проверки](android_0_7_0.md).
