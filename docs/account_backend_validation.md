# Сервер аккаунтов — проверка 28 октября 2026

ТЗ не изменялось. Реализован отдельный FastAPI-сервер аккаунтов и подключение
существующего интерфейса Flet через `account_gateway.py`.

## Фактические результаты

- `python -m unittest discover -s tests -v`: **83 теста прошли** на Python 3.12/Linux.
  Сохранились прежние проверки, добавлены API, реальный клиент-серверный обмен,
  запрет локального режима аккаунтов на Android без адреса API и обработка HTTP 401.
- HTTP API проверен через TestClient с настоящими SQLite-базами: регистрация,
  подтверждение почты, вход, профиль, настройки, смена пароля/email, восстановление,
  отзыв сессий и удаление аккаунта. Подстановка userId/roleName отклоняется.
- Клиент проверен с сервером в отдельном процессе и отдельной базе: формы Flet,
  профиль и настройки проходят по HTTP; локальный пароль не используется при
  ошибке сервера. Проверены совпадающие ID двух баз, сохранность прежних проектов,
  повторный вход и очистка только данных нужной привязки при удалении аккаунта.
- Явный выход без сети очищает клиентскую сессию и сообщает, что отзыв токена
  сервером не подтверждён. Обычный сбой сети не выполняет скрытый выход.
- Клиент не вызывает отправку почты даже при наличии переменной ключа в окружении.
  Все серверные почтовые сценарии в автотестах используют транспорт в памяти.
- Текущий `main.py` отдельно запущен с временной папкой данных: HTTP 200,
  настоящая WebSocket-регистрация Flet, получение элементов приложения и отсутствие
  нарушений FK в новой базе. Визуальное отображение этим не проверяется.
- Docker-образ собран. В среде с HTTPS-прокси использован доверенный CA-bundle
  через BuildKit secret; TLS-проверка не отключалась. Исправлены права чтения
  исходников для запуска непривилегированным пользователем.
- Контейнер запущен: проверены /health, регистрация, ответ 401 без Bearer, сохранение
  аккаунта после перезапуска с тем же томом. Процесс работает с UID 65534; ключ
  почты отсутствует. В образ не копируются Flet main.py и .env. Тестовые контейнер
  и том после проверки удалены; пользовательские данные не использовались.
- `pip check` и `git diff --check` прошли.

## Не подтверждено / остаётся открытым

- Пользователь подтвердил получение кода своей почтой в прежнем режиме приложения.
  Отправка реального письма из нового backend в этой среде не проверена: значения
  ключа и отправителя не переносились автоматически с компьютера пользователя.
- Публичный HTTPS-хостинг не развёрнут. Нужны хостинг с постоянным диском, адрес API
  и серверные секреты Resend. Подробная инструкция — `backend/README.md`.
- Android APK, состав готового APK, эмулятор/телефон и безопасное хранилище токена
  не проверялись. Ключа Resend в исходниках и клиентской конфигурации нет.
- Проекты, смеси, уроки и публикации остаются локальными. Межустройственная
  синхронизация и перенос существующих локальных аккаунтов/данных не выполнены.
- Серверная загрузка аватара, Google OAuth и административные функции не реализованы.

Наличие отдельного API закрывает часть подключения клиента к серверу, но не всё
ТЗ целиком. Инструкции по секретам относятся к процессу backend, а адрес API — к клиенту.
