# №31: этапы, фотографии и завершение проекта

Версия 0.15.0. Проект открывается отдельной страницей; редакторы этапов, фотографий, публикации и рецептов переключаются внутри неё. Создание проекта и поста сохраняется в модальном окне из общей кнопки «Создать».

- Название этапа хранится отдельно от необязательного описания (до 900 символов). Старые подписи остаются названиями без потери текста.
- В личном проекте можно отметить этап без фотографии и убрать фото выполненного этапа. Фото открывается маленькой кнопкой возле редактирования, без постоянного большого блока загрузки под каждым этапом.
- «Завершить проект» — отдельное действие. Нужны финальное фото и выполненные этапы; проект без этапов также можно завершить с финальным фото. Дата завершения записывается при этом действии. Простое достижение 100% этапов проект не завершает.
- Проект можно вернуть в работу. Снятие отметки с этапа или добавление невыполненного этапа также возвращает его в работу. Финальное изображение сохраняется; убрать его из завершённого проекта можно после возврата в работу.
- Для публикации финальное фото становится обложкой; каждый выбранный публикуемый этап должен иметь фото. Невыбранные личные этапы могут оставаться без фото. Не больше десяти фотографий вместе с обложкой. Личные заметки и дедлайн не подставляются в описание публикации.
- Подробности этапов сохраняются в опубликованной копии и при добавлении проекта читателем. Чужое фото результата не превращается в доказательство завершения личного проекта читателя. Параметры мастер-класса и выбор смесей/конкурса сохранены.
- Порядок меняется только перетаскиванием, со временным порядком до сохранения и отменой. После отпускания создаётся новый экземпляр списка: Flet 0.28 иначе восстанавливал старое визуальное расположение из своего кеша. Старые события не могут переместить строки повторно. Сохранение проверяет состав/старый порядок в одной транзакции.
- Удаление этапа перенесено в его редактор и требует отдельного подтверждения с названием. Кнопок удаления в режиме перетаскивания нет.

## Совместимость

SQLite добавляет поля без удаления старых этапов, фотографий и дат. Для старых завершённых проектов финальное фото берётся из последнего этапа с фото в сохранённом порядке; если фотографии нет, проект требует нового подтверждения завершения. Известная старая дата не выдумывается и не заменяется при миграции.

JSON проекта теперь версии 2: отдельное описание, финальное фото и признак завершения. Версия 1 импортируется. Личные снимки, восстановление и защищённые копии используют новый формат проекта; при переносе снимком сохраняются точные байты фотографий, чтобы не создавать ложные конфликты синхронизации.

**Обновить Wi-Fi-сервер до пакета 0.15 нужно для новых публикаций проектов и переноса снимков с новым форматом.** Обычные старые публикации и ранее опубликованные текстовые шаги читаются. Новые публикации без фото выбранных этапов отклоняются и на сервере. APK определяет поддержку нового проекта через `/capabilities` и сообщает об устаревшем сервере. При недоступной сети сохраняется прежняя очередь отправки.

Английский и общая двухпользовательская приёмка остаются обязательным следующим блоком №32. Нативные жесты перетаскивания и системные файлы требуют проверки на физическом Android.

## Проверки

Все 486 автотестов проходят. Автотесты проверяют миграцию старой базы, права владельца, обязательность финального фото, идемпотентность завершения, JSON v1/v2, точное восстановление фотографий снимком и публикацию через отдельную серверную базу с копированием вторым аккаунтом.

В браузере проверены реальное перетаскивание мышью с изменением видимого порядка до сохранения и порядка в SQLite после сохранения, добавление описания, выполнение без фото этапов, запрет завершения без результата, загрузка результата и завершение, публикация, скачанный JSON v2 и отмена удаления. Проверены ширины 320/390/820 и тёмная тема.
