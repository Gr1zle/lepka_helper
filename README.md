# Android 0.12.0 — исправление PNG, камера, PDF и фотореференсы

[Скачать APK 0.12.0](https://github.com/Gr1zle/lepka_helper/raw/refs/heads/artifacts/android-demo-20261031/lepka-helper-0.12.0-tools-arm64.apk) · [Сервер 0.12.0](https://github.com/Gr1zle/lepka_helper/raw/refs/heads/artifacts/android-demo-20261031/lepka-server-0.12.0.zip).

Android 9+, ARM64, около 38 МБ, versionCode 2009. Установить поверх 0.11.0 без удаления приложения: подпись сохранена. Исходники: feature/color-camera-references, c974008, PR №28. Все 459 тестов прошли локально. Проверены актуальные исходники/ресурсы APK, подпись, целостность, нативные операции файлов/камеры, FileProvider, прежние Keystore/receiver/видеоплеер; личных баз/сессий/секретов нет.

PNG больше не записывается через Python Path для Android content://. Системный документ получает байты, результат читается обратно и сверяется по размеру/SHA256. На ПК — атомарная запись с обработкой пустого файла выборщика. Старый файл 0 байт нужно экспортировать заново. Сохранение PNG/PDF и референсов использует общий механизм.

«Цвета»: камера или фото → выбор участка → RGB/HEX/ближайший цвет; PDF A4, сантиметры по массе/длине целого бруска, поиск цветов и смесей. Камера Android запускается через системное приложение; на веб есть камера браузера/выбор снимка, на ПК — выбор фото. «3D-галерея» → «Мои фотореференсы»: обрезка, удаление однотонного фона, сохранение/экспорт прозрачного PNG, до 20 изображений/40 МБ на аккаунт/API. Это не нейросетевое удаление сложного фона. Новые референсы пока не входят в перенос снимком №24.

Проверка на устройстве: выбрать сохранённую смесь и повторить экспорт PNG в Downloads, открыть файл и проверить ненулевой размер; проверить PDF и отмену выбора файла. Затем снять фото, коснуться объекта и применить HEX. Физическая камера и Android-провайдеры документов ещё требуют проверки пользователя; программные тесты не заменяют её. Браузерные скачивания/снимок/прозрачный PNG и интерфейс 320 px проверены на синтетических данных.

Сервер: остановить прежний процесс, распаковать новую папку отдельно, использовать прежний --data-dir и сохранить LepkaHelperServer/accounts.db. Письма выключены по умолчанию. [Отчёт №28](https://github.com/Gr1zle/lepka_helper/blob/feature/color-camera-references/docs/color_camera_references.md) · [Две следующие группы](https://github.com/Gr1zle/lepka_helper/blob/feature/color-camera-references/docs/remaining_work.md).
