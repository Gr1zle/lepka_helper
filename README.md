# Lepka Helper

Мобильное приложение-помощник для лепки из пластилина, выполненное для курсовой работы.

## Реализовано

- Splash Screen и Onboarding.
- Регистрация и вход по email/паролю.
- Главная лента с идеями и карточками.
- Поиск уроков по названию, тегам и категориям.
- Color Mixer: смешивание цветов, расчёт процентов и граммов, сохранение рецептов.
- Подбор ближайшего рецепта по HEX-коду цвета.
- Личные проекты с категориями, дедлайнами, этапами и прогрессом.
- Профиль пользователя: никнейм, биография, возрастная категория, любимые цвета.
- Настройки: светлая/тёмная тема, язык, уведомления.
- Сообщество: публикации, лайки, комментарии, удаление своих записей.
- Удаление аккаунта с подтверждением паролем.
- Локальное хранение данных в SQLite.

## Запуск

```bash
pip install flet
python main.py
```

## Сборка APK

```bash
pip install flet
flet build apk
```

Перед сборкой установите Flutter SDK и Android Studio.

## Проверка по сценарию

1. Запустить `python main.py`.
2. Нажать «Начать» и пройти onboarding.
3. Зарегистрировать пользователя.
4. Открыть «Цвета», выбрать цвета и сохранить смесь.
5. Открыть «Поиск», найти урок по слову `кот`.
6. Создать проект во вкладке «Проекты».
7. В профиле изменить тему и сохранить настройки.
8. Создать публикацию, поставить лайк и комментарий.
