# Lepka Helper

## Описание проекта

**Lepka Helper** — учебное приложение-помощник для лепки на Python и Flet. Оно помогает планировать проекты по этапам, подбирать и смешивать цвета, изучать уроки, просматривать 3D-модели и делиться работами с другими пользователями. Интерфейс доступен на русском и английском языках.

Приложение работает на Android и ПК. Для общего сообщества сервер FastAPI запускается на компьютере, а телефон подключается к нему через ту же сеть Wi-Fi. Хостинг и Docker для учебного запуска не требуются.

## Установка и запуск

### Android

1. [Скачать APK 0.19.0](https://github.com/Gr1zle/lepka_helper/raw/refs/heads/artifacts/android-demo-20261031/lepka-helper-0.19.0-final-fixes-arm64.apk) на телефон с Android 9 или новее (ARM64).
2. Открыть APK и при необходимости разрешить установку из этого источника.
3. Запустить приложение. Для общего сообщества указать адрес сервера вида `http://192.168.1.10:8000`, где IP-адрес принадлежит компьютеру в той же сети Wi-Fi.

### Сервер и версия для ПК

Нужен Python 3.12. В корне проекта создайте окружение для сервера и запустите его:

```powershell
py -3.12 -m venv .server-venv
.\.server-venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.server-venv\Scripts\python.exe -m scripts.run_wifi_server --data-dir "$HOME\LepkaHelperServer" --port 8000
```

Компьютер должен оставаться включённым, пока телефон пользуется сервером. Команды для локального запуска клиента на ПК, настройки почты, создания первого администратора и резервных копий приведены в [краткой консольной инструкции](CONSOLE_COMMANDS.md).

После первого запуска сервера создайте обычный тестовый аккаунт:


## Основные возможности

- **Главная и сообщество:** поиск и фильтры, лента работ, публикации с фотографиями, лайки, комментарии, жалобы и задания.
- **Цвета:** 12 базовых цветов, расчёт пропорций смеси, подбор цвета по фотографии или снимку камеры, сохранение рецептов и экспорт PNG/PDF.
- **Проекты:** категории, сроки, этапы с описанием и фото, изменение порядка, итоговая фотография, завершение и публикация работы.
- **Обучение и 3D:** встроенные уроки, учебный каталог, просмотр моделей и импорт OBJ/MTL.
- **Профиль и данные:** настройки языка и темы, уведомления, экспорт и импорт поддерживаемых данных в JSON.

## Особенности учебной версии

Личные проекты и смеси хранятся локально; публикации и общие данные доступны через сервер. Без доступного сервера общее сообщество не синхронизируется. Расчёт смеси даёт приблизительный цвет на экране и не моделирует физическое смешивание пластилина.
