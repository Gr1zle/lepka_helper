# Lepka Helper — помощник для лепки

Курсовой проект на Python, Flet и SQLite. Первый этап первого дня: восстановление запуска существующего приложения.

## Запуск на Windows

Проверенная версия Python — 3.12. В терминале VS Code, открытом в папке `lepka_helper`, выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Активировать окружение не требуется. При следующих запусках нужна только последняя команда. Если `py -3.12` сообщает об отсутствии версии, установите Python 3.12.

Приложение открывается в браузере по адресу http://127.0.0.1:8550. Для другого порта добавьте `--port 8551`.

Для отдельного окна сначала установите настольный клиент:

```powershell
.\.venv\Scripts\python.exe -m pip install "flet[desktop]==0.28.3"
.\.venv\Scripts\python.exe main.py --desktop
```

Первую проверку выполните в браузере. Отдельное окно Windows и APK пока не проверены.

## Тестовый вход

- Пароль: `Test123456`

Пользователь создаётся при первом открытии приложения. Если в существующей базе его пароль уже изменён, используйте изменённый пароль. Базу удалять не нужно.

## Структура и данные

- `main.py` — запуск и маршрутизация.
- `views/` — экраны приложения.
- `*_service.py` — функции предметной области.
- `database.py` — SQLite и запросы.
- `password_service.py` — общий формат и проверка паролей.
- `app_paths.py` — папка данных, независимая от папки запуска.
- `tests/test_startup.py` — проверки запуска и исправленных ошибок.

При локальном запуске база `lepka_helper.db` и состояние `app_state.json` находятся рядом с приложением. Можно задать другую папку через `LEPKA_DATA_DIR`. В упакованной среде учитывается `FLET_APP_STORAGE_DATA`; мобильная сборка ещё не протестирована.

Папка `backend` рядом с `lepka_helper` содержит отдельную серверную заготовку. Основное приложение её не использует: оно работает с локальными сервисами и SQLite. Запускать её для проверки интерфейса не требуется.

## Проверка после установки

1. Дождаться заставки. В новой копии пройти вводные экраны.
2. Войти тестовым пользователем.
3. Открыть «Главная», «Поиск», «Цвета», «Проекты», «Профиль».
4. Выйти и зарегистрировать собственный тестовый аккаунт.
5. Сменить пароль в профиле, затем выйти и войти с новым паролем.
6. Открыть «Забыли пароль?» и проверить появление диалога.

Автоматические проверки из папки `lepka_helper`:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Проверка проектов

Дедлайн необязателен. Если он указан, требуется существующая календарная дата
строго в формате `ДД.ММ.ГГГГ`, например `25.04.2026`. Пробелы по краям
убираются, прошедшие даты допускаются. Это правило соответствует текущему
интерфейсу; сверка с ТЗ требует предоставления самого документа.

В «Проектах» проверьте следующие действия на специально созданном тестовом проекте:

1. Введите `НЕ ДАТА`, затем `31.04.2026`: сохранение должно отклоняться с сообщением.
2. Создайте проект с пустым дедлайном: в карточке появится «Без дедлайна».
3. Добавьте два этапа, отметьте один: прогресс станет 50%.
4. Удалите незавершённый этап: прогресс станет 100%.
5. Войдите в другой аккаунт: этот проект не должен отображаться.
6. Вернитесь в первый аккаунт и удалите тестовый проект: вместе с ним удаляются оставшиеся этапы.

Команда автоматических проверок приведена выше. `tests/test_projects.py`
проверяет также подстановку чужих идентификаторов на уровне сервисов и SQL,
удаление всех этапов и откат транзакции при ошибке. `tests/test_startup.py`
проверяет обработчики формы проектов с настоящими элементами Flet и транспортом
в памяти. Каждый тест использует временную SQLite-базу; пользовательская база
не удаляется и не изменяется. Ранее возникшие записи-сироты автоматически
не удаляются: для очистки старых данных нужна отдельная проверка и резервная копия.

## Текущие ограничения

В коде есть формы регистрации, профиля, смешивания цветов, проектов, уроков и публикаций. Первый этап проверяет запуск и основные переходы; полные испытания каждой функции ещё предстоят.

Google-вход — демонстрационная кнопка. Код восстановления показывается в приложении, отправки письма нет. «Запомнить меня» не восстанавливает вход после перезапуска. Язык сохраняется в настройках, но полного английского перевода нет. Публикации хранятся локально, сетевое сообщество не подключено. Экспорт смеси пока текстовый. Полноценный 3D, AR, push и серверная синхронизация не подтверждены и требуют отдельной работы. Эти ограничения нужно учитывать при согласовании объёма курсовой и итогового ТЗ.
