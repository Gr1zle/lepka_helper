Пробная APK-сборка 0.6.0 для Android 9+ (ARM64). Локальный деморежим без сервера.

Установка и проверка
1. Скачайте lepka-helper-0.6.0-demo-arm64.apk из Assets и откройте на телефоне. При запросе Android разрешите установку для приложения, которым открываете APK.
2. Войдите: test@email.com / Test123456.
3. Проверьте пять вкладок, смешивание/сохранение цветов, создание проекта и этапа с фото, выбор аватара, публикацию с фотографией.
4. Закройте и снова откройте приложение: проверьте сохранность проекта и палитры.

Публикации и комментарии этой сборки хранятся только на телефоне. Общего сообщества между устройствами и настроенной почты нет. Для них потребуется отдельная серверная сборка с доступным HTTPS API.

Исходники: ветка build/android-local-demo, коммит 2883c0b. Основная ветка release/coursework-review не изменена. Флаг scripts/prepare_android.py --local-demo включает явный местный режим; обычная сборка продолжает требовать сервер.

Проверки: 229 тестов OK; pip check и git diff --check пройдены. APK собран Flet 0.28.3 / Flutter 3.29.2 / JDK 17. Подпись APK v2 и целостность архивов проверены; minSdk 28, targetSdk 35, только arm64-v8a. Проверены актуальный код и флаг деморежима внутри APK. Пользовательские базы и .env отсутствуют, почтовые переменные исключены из окружения сборки.

Установка и запуск на физическом устройстве ещё не проверены. APK подписан тестовым ключом для этой проверки.
