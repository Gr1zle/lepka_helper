# Помощник по лепке — контрольная версия 0.6.0

Версия для предварительной проверки курсовой от 29.10.2026. Сегодня проверяется
приложение на компьютере в браузере. ТЗ не сокращено; невыполненные требования
перечислены в [описании версии](docs/review_version.md).

## Быстрый запуск на Windows

Распакуйте архив в отдельную папку. Установите Python 3.12, откройте PowerShell
в этой папке и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --local
```

Если окружение уже установлено, достаточно последней команды. Приложение
откроется по адресу `http://127.0.0.1:8550`. Установка зависимостей и первая
загрузка ресурсов Flet могут требовать интернет. Отдельный сервер API, хостинг
и почта для тестового входа не нужны. Это архив исходников, не установщик EXE/APK.

Вход: `test@email.com` / `Test123456`. В существующей базе изменённый пароль
не сбрасывается. Флаг `--local` выбирает местный режим только для этого процесса,
не меняет адрес API в файле и серверные данные.

## Что показать проверяющему

1. «Цвета»: два цвета 50/50, вес 100 г → компоненты по 50 г. Сохранить смесь,
   открыть её и экспортировать PNG.
2. «Поиск»: открыть встроенный урок, отметить материал и шаг, вернуться и
   открыть снова — прогресс сохранён.
3. «Проекты»: создать проект с датой или без неё; добавить этап, фото и смесь
   из палитры. Отметить выполнение, проверить прогресс.
4. Опубликовать проект как мастер-класс со сложностью, временем, материалами и
   инструментами. На главной открыть его, перейти между шагами и сохранить рецепт.
5. «Профиль»: выбрать аватар, изменить ник и любимые цвета, сохранить. Переключить
   тему, выйти и войти снова. Удаление тестового проекта сначала отменить,
   затем подтвердить.

В локальном режиме сообщество общее для пользователей этой базы. Для второго
аккаунта с почтовой регистрацией и общего сообщества через API используйте
[серверную инструкцию](docs/server_community.md); подтверждение регистрации
и восстановление пароля требуют настроенной почты.

## Если используется ваш прежний сервер

Запускайте приложение без `--local`, с прежним `LEPKA_API_URL`. Перезапустите API
и приложение с прежними каталогами данных. Для отдельного серверного тестового
аккаунта в терминале с вашим `LEPKA_SERVER_DATA_DIR` выполните:

```powershell
.\.venv\Scripts\python.exe -m scripts.create_server_demo
```

Команда работает с существующей `accounts.db`, создаёт только обычный тестовый
аккаунт и не меняет существующие пароли. Вход тот же. Для реальной регистрации
подтверждение почты остаётся обязательным. Ключ почты нужен только серверу.

## Проверки и данные

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты создают временные базы и фотографии. Рабочая база не включена в архив;
при первом запуске создаётся новая. Если обновляете существующую копию,
сохраните её прежнюю базу и каталог данных. Исходные фото на диске не изменяются.

Версия и сведения о составе находятся в `REVIEW_MANIFEST.json`. Скриншоты и
фактические границы готовности — в `docs/review_version.md`. Android в эту
контрольную поставку не входит и работоспособным здесь не объявляется.
