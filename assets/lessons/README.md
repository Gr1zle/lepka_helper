Авторские схематичные SVG-иллюстрации для встроенных уроков. Это демонстрационные рисунки фигурок, а не фотографии реальных работ и не пошаговые фото. Внешние изображения и сетевые ссылки не используются.

Текущие уроки используют 37 PNG из `steps/`: отдельная геометрическая схема для каждого из 37 этапов шести уроков. Они созданы командой `python -m scripts.generate_learning_models` из встроенных авторских моделей и показывают накопление деталей. Это схемы, а не фотографии процесса; некоторые завершающие этапы используют ту же геометрию. Старые SVG сохранены для совместимости. Превью готовых фигурок находятся в `assets/models/`.
