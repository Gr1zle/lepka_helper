# Встроенные учебные модели

Шесть оригинальных упрощённых фигурок: котик, пицца, дракон, машинка, аниме-персонаж и медвежонок. Геометрия создаётся из примитивов скриптом `scripts/generate_learning_models.py`; сторонние модели, текстуры и изображения не используются. OBJ содержит треугольники, MTL — собственные однотонные цвета. PNG-превью и схемы этапов строятся тем же программным проектором, что используется просмотрщиком.

Воспроизведение: `python -m scripts.generate_learning_models` из корня проекта с установленными зависимостями. Это геометрические пособия, не 3D-сканы и не фотографии пластилина. Для импорта в сторонний редактор держите OBJ и соответствующий MTL рядом. Просмотрщик поддерживает встроенный каталог и личный импорт OBJ/ZIP с OBJ/MTL. Личные модели сохраняются в базе устройства, в эту папку не записываются. glTF/USDZ, текстуры и AR не добавлены. Подробнее: `docs/model_import_fullscreen.md`.
